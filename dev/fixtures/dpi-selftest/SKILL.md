# dpi-selftest

这是一个**测试夹具**，不是真技能。

它的存在只为证明一件事：面板能把一个「根目录带 SKILL.md 的文件夹」识别成 Skill、
剥离包装目录、落位到 `$DSH_HOME/skills/<name>/`，并在安装后确认它出现在技能目录清单里。

看到这段文字说明安装链路通了。可以用面板里的「回滚到安装前」把它删掉。
