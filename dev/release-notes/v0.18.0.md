## v0.18.0 — 设置里能自选 AI 模型 + 第一次打开面板的引导

> 上一版（0.17.0）回答的是「装什么」；这一版回答「AI 审查到底用谁的模型」。

### 新增

- **设置 → AI 模型**：两档 —— `跟随 DSH 默认` / `自选模型`。
  - 自选列表来自宿主真实目录（`llm.listProviders()` + `llm.listModels()`）：**5 分钟缓存**、每个 provider **5 秒硬超时**、一个 provider 失败只标它自己；列不出来时可手动填 provider / model。
  - 选中的模型对 **安装后的 AI 语义审查 / AI 推荐 / AI 辅助添加来源 / 网页解析** 全部生效；改完不用重启，下一次调用就跟上。
  - 不设置 = 跟随 DSH 默认模型；写坏 / 缺一半自动回落到跟随默认，不会让面板报错。
- **第一次打开面板的引导**（只出现一次）：说清模型用在哪三处、现在用哪个、材料会发给谁（代码片段会发给所选服务商，别用免费中继做安全审查），并给两条路：`去选一个模型` / `先用默认（稍后再说）`。
- **审查结果更透明**：新增 `model` + `modelSource`（自选 / 跟随默认）；调用失败时也写清「本来是哪个模型」。`install_hub_status` 多一行「AI 模型：provider/model（来源）」。

### 行为与兼容

- **默认行为不变**：`aiModel = null`，即跟随 `agentDefaultModel`（DSH「设置 → 模型」里的默认模型）。
- 没有可用模型时**如实报错**，不会静默换一个模型。
- 新增宿主路由：`GET /plugin-installer/models`（可选模型目录）、`GET/POST /plugin-installer/onboarding`（首次引导状态）；`/ai-status` 与 `/state` 带当前选择与引导状态。
- **客户端（面板 UI）需要重启一次 DSH** 才看到新设置区与引导；宿主半边重载插件即可。

### 验证

- `host_selfcheck` **1163** / `dev/audit.mjs` **214** / `dev/render-check.cjs` **275**，全 0 FAIL。
- 新增离线探针 `dev/probe-model-choice.mjs`：**23 项**（设置归一化 / 自选>默认 / `askLlm` 真用上 / 审查记录 / 目录失败隔离与超时 / 路由与文案接线）。
- 真机：`/models` 返回 **135** 个模型（多个 provider）；`POST /settings` 自选 → `source=custom`，写坏 → 自动回默认；`POST /onboarding` → `firstRun=false`（验收后已还原）。
