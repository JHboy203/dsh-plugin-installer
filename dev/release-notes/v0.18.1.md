## v0.18.1 — 引导可以重看 + 发版流程固化

### 新增

- **设置 → AI 模型 → 「再看一次引导」**：`POST /plugin-installer/onboarding {modelGuideSeen:false}`
  把 `modelGuideSeenAt` 清回 `null`，面板立刻重播那段说明 —— **不再需要手改 `data/onboarding.json`**。
  起因：0.18.0 验收时误点一次「看过了」，就差点让用户永远看不到首次引导。
- **`dev/release.mjs`**（默认 dry-run，`--apply` 才写）：一条命令发版。
  顺序固化为「只读检查（工作区干净 / HEAD 已在远端 / tag 与 release 不存在）→ API 建 tag →
  `gh release create --verify-tag` → 改仓库描述 → 校验 `releases/latest`」。
  2026-11-01 实测：`gh release create --target <短 sha>` 会被 GitHub 回 422（`target_commitish is invalid`），
  上面这个顺序是唯一能走通的路。
- 配套：`dev/repo-meta.json`（仓库介绍，≤350 字符 + topics）、`dev/release-notes/v<tag>.md`（Release 正文）。

### 说明
